# ☁️ 중계 서버 배포 안내 (Cloudflare, 휴대폰으로 가능)

중계 서버를 한 번 만들어 두면 **국토부 API 키 하나로 여러 사람이** 앱을 쓸 수 있습니다.
사용자는 키 발급 없이 앱 설치 + 서버 주소 입력만 하면 됩니다.

```
[사용자 휴대폰 앱] ──▶ [내 중계 서버 (Cloudflare Worker)] ──▶ [국토교통부 API]
                         · 내 API 키는 여기에만 저장
                         · 결과를 저장해 두고 재사용 (같은 지역은 100명이 봐도 국토부 호출 1번)
```

준비물: 국토부 API 키(매매·전월세 둘 다 활용신청된 것), Cloudflare 계정(기존 계정 그대로 사용 가능)

> 📱 휴대폰에서 Cloudflare 대시보드가 불편하면, 브라우저 메뉴에서 **"데스크톱 사이트"** 를 켜면 편합니다.

---

## 1단계. 중계 서버 코드 복사

1. 휴대폰 브라우저로 아래 주소를 엽니다 (코드만 보이는 화면).
   https://raw.githubusercontent.com/happyfamily1984/apt-alert-app/ccr-49f0f249-0f8r45/worker/worker.js
2. 화면을 길게 눌러 **전체 선택 → 복사** 합니다.
   (첫 줄 `// 실거래 알리미 중계 서버` 부터 마지막 `}` 까지 전부)

---

## 2단계. Worker 만들기

1. https://dash.cloudflare.com 로그인 (기존 계정 그대로)
2. 왼쪽 메뉴 **Workers & Pages** (또는 **컴퓨팅(Workers)**) 선택
3. **생성(Create)** → **Worker 생성** → **"Hello World" 템플릿으로 시작**
4. 이름을 `apt-alert` 로 바꾸고 **배포(Deploy)**
   - 기존에 쓰던 Worker와 **별개로** 새로 만들어집니다. 기존 앱에는 영향 없습니다.
5. 배포 완료 화면에서 **코드 편집(Edit code)** 을 누릅니다
6. 편집기 안의 기존 코드를 **전부 지우고**, 1단계에서 복사한 코드를 **붙여넣기**
7. 오른쪽 위 **배포(Deploy)** 를 누릅니다

---

## 3단계. 국토부 API 키를 비밀 변수로 넣기 (중요)

> 🔒 키는 **코드에 직접 쓰지 말고** 꼭 이 방법으로 넣으세요. 다른 사람이 볼 수 없습니다.

1. `apt-alert` Worker 화면 → **설정(Settings)** 탭
2. **변수 및 비밀(Variables and Secrets)** → **추가(Add)**
3. 유형: **비밀(Secret)** 선택
   - 변수 이름: `MOLIT_KEY` (대문자 그대로)
   - 값: 공공데이터포털 **일반 인증키** 붙여넣기 (Encoding/Decoding 아무거나)
4. **배포(Deploy)** 또는 **저장** 을 누릅니다

---

## 4단계. (권장) 캐시 저장소 연결

여러 사람이 쓸 때 국토부 호출을 더 크게 줄여줍니다. 무료입니다.

1. 왼쪽 메뉴 **저장소 및 데이터베이스(Storage & Databases)** → **KV** → **네임스페이스 생성(Create)**
   - 이름: `apt-alert-cache` → 추가
2. 다시 `apt-alert` Worker → **설정(Settings)** → **바인딩(Bindings)** → **추가(Add)** → **KV 네임스페이스**
   - 변수 이름: `CACHE` (대문자 그대로)
   - KV 네임스페이스: `apt-alert-cache` 선택 → **배포/저장**

---

## 5단계. 동작 확인

1. Worker 화면 위쪽에 있는 주소를 누릅니다. 예: `https://apt-alert.내계정이름.workers.dev`
2. 아래처럼 보이면 성공입니다.
   ```
   {"ok":true,"service":"apt-alert-proxy","version":"1.0.0","keyConfigured":true,"kvCache":true}
   ```
   - `keyConfigured:false` → 3단계(MOLIT_KEY)를 다시 확인
   - `kvCache:false` → 4단계를 안 한 경우 (안 해도 동작은 합니다)
3. 실제 데이터 확인 (주소 뒤에 붙여서 열기):
   `/molit/trade?LAWD_CD=11680&DEAL_YMD=202610`
   → `<resultCode>000</resultCode>` 와 아파트 이름들이 보이면 완벽합니다.
   - `"error": "중계 서버의 국토부 API 오류: SERVICE_KEY..."` → 키가 틀렸거나 매매 API 활용신청이 안 된 경우
   - `DEAL_YMD` 는 확인하는 시점의 **지난달**(YYYYMM)로 바꿔서 넣으세요

---

## 6단계. 앱에 서버 주소 넣기

1. 실거래 알리미 앱 → **⚙️ 설정** → **데이터 연결**
2. **중계 서버 주소** 칸에 `https://apt-alert.내계정이름.workers.dev` 입력
3. **중계 서버 저장하고 테스트** → `✅ 연결 성공!` 이면 끝

다른 사람에게 줄 때도 **APK + 서버 주소**만 알려주면 됩니다.

### 서버 주소를 APK에 미리 넣어 배포하기 (선택)
사용자가 주소 입력도 없이 설치만 하면 바로 쓰게 하려면:
1. GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables 탭 → New repository variable**
   - Name: `PROXY_URL` / Value: `https://apt-alert.내계정이름.workers.dev`
2. (서명키 Secret 2개가 등록돼 있어야 함 → 사용설명서 6단계)
3. **Actions → Android APK → Run workflow** → 완료 후 **Releases** 에 서버 주소가 들어간 APK가 올라옵니다.

## 사용량 · 비용

| 항목 | 무료 한도 | 이 앱 기준 |
|---|---|---|
| Cloudflare Worker 요청 | 하루 10만 건 (**계정 전체 공유**, 기존 앱 포함) | 사용자 1명이 하루 수십~수백 건 |
| Cloudflare KV 쓰기 | 하루 1,000건 | 조회되는 지역 수에 비례 (사용자 수와 무관) |
| 국토부 API (개발계정) | API별 하루 1만 건 | 캐시 덕분에 지역 수에 비례 |

- 사용자가 많아져 국토부 한도가 부족하면 공공데이터포털에서 **운영계정 신청**(활용사례 등록)으로 한도를 늘릴 수 있습니다.
- Cloudflare 대시보드의 Worker **메트릭(Metrics)** 에서 요청 수를 볼 수 있습니다.

## (선택) 아무나 쓰지 못하게 막기

Worker 설정에 비밀 변수 `APP_TOKEN` 을 추가하면, 같은 토큰이 들어간 앱만 서버를 쓸 수 있습니다.
토큰을 넣은 APK는 GitHub Actions에서 Secret `PROXY_TOKEN` 에 같은 값을 넣고 빌드하면 만들어집니다.
(APK를 분해하면 토큰을 꺼낼 수는 있으니, 완벽한 보안이 아니라 "무단 사용 방지" 정도로 생각하세요.)
