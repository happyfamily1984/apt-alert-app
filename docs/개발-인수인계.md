### 새 세션에서 서명키 복원
1. `서명키-보관용.txt`의 BEGIN~END 사이를 base64 디코드 → `apt-alert-release.jks`
2. `android/keystore.properties` 작성 (git에 올리지 않음):
   ```
   storeFile=/절대경로/apt-alert-release.jks
   storePassword=<비밀번호>
   keyAlias=aptalert
   keyPassword=<비밀번호>
   ```
3. 또는 GitHub 저장소 Secrets에 `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD` 등록 → Actions가 서명된 APK/AAB를 Releases에 올림 (가장 안전)

## 빌드 방법 (새 세션)
```bash
npm install && npm test                      # 서버·중계 서버 테스트
# Android SDK 필요: platforms;android-36, build-tools;36.0.0 (sdkmanager로 설치)
echo "sdk.dir=/opt/android-sdk" > android/local.properties
cd android && ./gradlew testReleaseUnitTest assembleRelease bundleRelease
```
- 버전 올리기: `android/app/build.gradle.kts`의 `VERSION_CODE`/`VERSION_NAME` 기본값 (코드는 항상 증가)
