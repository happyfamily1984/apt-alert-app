# 📲 Google Play 출시 안내 (아파트 실거래가 알리미)

준비물은 모두 만들어 두었습니다.

| 준비물 | 위치 |
|---|---|
| 출시 파일 (AAB) | `release/apt-alert-1.4.0.aab` |
| 스토어 문구·정책 답변 | `docs/play-store/스토어-등록정보.md` |
| 아이콘·대표 이미지·스크린샷 | `docs/play-store/` 폴더 |
| 개인정보처리방침 | https://apt-alert.k-rebirth7-03a.workers.dev/privacy |
| 업로드 서명키 | 처음에 받은 `서명키-보관용.txt` (**절대 잃어버리지 마세요**) |

---

## 1단계. 개발자 계정 만들기 (최초 1회, 25달러)
1. https://play.google.com/console 접속 → 구글 계정으로 로그인
2. **개인** 계정 선택 → 이름·주소·전화번호 입력, 신분증 인증
3. 등록비 **25달러** 결제 (한 번만)
4. 본인 인증이 끝나기까지 며칠 걸릴 수 있습니다.

> ⚠️ 2023년 11월 이후 만든 **개인 계정**은 바로 정식 출시가 안 되고, **테스터 12명 이상이 14일 동안 비공개 테스트**를 해야 정식 출시를 신청할 수 있습니다 (4단계).

## 2단계. 앱 만들기
1. Play Console → **앱 만들기**
2. 앱 이름: `아파트 실거래가 알리미` / 기본 언어: 한국어 / 앱 / 무료
3. 정책 동의 체크 → **앱 만들기**

## 3단계. 앱 설정 (대시보드의 "앱 설정" 항목을 차례로)
`docs/play-store/스토어-등록정보.md`의 답변을 그대로 넣으면 됩니다.
- **개인정보처리방침**: `https://apt-alert.k-rebirth7-03a.workers.dev/privacy`
- **앱 액세스 권한**: 모든 기능을 제한 없이 사용 가능
- **광고**: 광고 없음
- **콘텐츠 등급**: 설문에서 모두 '아니요' → 전체이용가
- **타겟층**: 만 18세 이상
- **데이터 보안**: 데이터 수집·공유 '아니요', 전송 중 암호화 '예'
- **금융 기능 / 건강 / 뉴스 / 정부 앱**: 해당 없음
- **스토어 등록정보**: 짧은 설명·자세한 설명 붙여넣기, 아이콘·대표 이미지·스크린샷 업로드, 카테고리 '주택/홈', 연락처 이메일

## 4단계. 비공개 테스트 (개인 계정 필수, 14일)
1. **테스트 → 비공개 테스트 → 트랙 만들기**
2. **테스터**: 이메일 목록 만들기 → 테스터 **12명 이상**의 구글(Gmail) 주소 입력
3. **새 버전 만들기**
   - **Play 앱 서명**: "Google에서 생성한 앱 서명 키 사용"(기본값) 그대로 → 계속
   - **App Bundle 업로드**: `apt-alert-1.4.0.aab`
   - 출시 노트: `첫 출시`
4. **검토 후 출시** → 구글 검토 (보통 1~3일)
5. 승인되면 나오는 **테스트 참여 링크**를 테스터들에게 보내기 → 각자 링크에서 "테스터 되기" 후 Play 스토어에서 설치
6. 테스터 12명 이상이 **14일 연속** 참여 상태를 유지해야 합니다.

## 5단계. 프로덕션(정식) 출시 신청
1. 14일이 지나면 대시보드에 **프로덕션 액세스 신청** 버튼이 열립니다.
2. 테스트 소감 질문(테스터 모집 방법, 받은 피드백 등)에 답하고 신청 → 검토(최대 7일 정도)
3. 승인되면 **프로덕션 → 새 버전 만들기** → 같은 AAB(또는 새 버전) 업로드 → 출시

## 업데이트할 때
- 새 버전 AAB는 제가 만들어 드리거나, GitHub Actions가 자동으로 만듭니다(서명키 Secret 등록 시).
- **버전 코드는 올라가기만 해야** 합니다 (지금 1.4.0 = 15).
- 업로드 서명키(`서명키-보관용.txt`)로 서명된 파일만 올릴 수 있습니다. **잃어버리면 Play Console에서 '업로드 키 재설정'을 요청해야 합니다.**

## 꼭 알아두세요
- **지금 APK로 설치한 앱은 Play 스토어 버전으로 바로 업데이트되지 않습니다.** Play가 앱을 자체 서명키로 다시 서명하기 때문입니다. Play 버전을 설치하려면 기존 앱을 **삭제 후 설치**해야 하고, 알림 받는 단지는 다시 등록해야 합니다.
- **패키지 이름**은 `com.aptalert.app`입니다. 업로드할 때 "이미 사용 중인 패키지 이름"이라고 나오면 알려주세요 — 이름을 바꿔 다시 만들어 드립니다.
- 공공데이터를 쓰는 앱이라 앱 설명과 앱 안에 "정부기관과 무관" 문구와 출처를 넣어 두었습니다 (Play 정책상 필요).
- 국토부 API는 **개발계정 하루 1만 건** 한도가 있습니다. 사용자가 많아지면 공공데이터포털에서 **운영계정 신청**(활용 사례 등록)으로 한도를 늘리세요.
