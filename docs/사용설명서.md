# 📱 실거래 알리미 사용 설명서 (PC 없이 휴대폰만으로)

이 앱은 **서버나 PC 없이 휴대폰 안에서 모든 것을 처리**합니다.
휴대폰이 직접 국토교통부에서 실거래 자료를 받아오고, 백그라운드에서 주기적으로 새 거래를 확인해 알림을 띄웁니다.
비용은 **0원**입니다 (국토부 API 무료).

> 안드로이드 8.0 이상 휴대폰에서 동작합니다. (아이폰은 APK 설치 불가)

---

## 1단계. 앱 설치 (3분)

1. 휴대폰에서 APK 파일을 다운로드합니다.
   - 받은 파일 `실거래알리미-1.1.6.apk`, 또는
   - GitHub 저장소의 `release/apt-alert-1.1.6.apk` → **Download**(⬇) 버튼
2. 다운로드 완료 알림(또는 **내 파일 → 다운로드**)에서 APK를 누릅니다.
3. "이 출처의 앱 설치를 허용하시겠습니까?"가 나오면 **설정 → 이 출처 허용**을 켜고 뒤로 갑니다.
   - 삼성: 설정 → 애플리케이션 → (크롬/내 파일) → **출처를 알 수 없는 앱 설치** → 허용
4. **설치**를 누릅니다.
   - "Play 프로텍트에서 차단" 경고가 뜨면 **세부정보 더보기 → 무시하고 설치**를 누르세요.
     (플레이스토어를 거치지 않은 개인 앱이라 나오는 일반적인 경고입니다)
5. 홈 화면의 **실거래 알리미** 아이콘을 눌러 실행합니다.

---

## 2단계. 데이터 연결 방법 고르기

- **중계 서버가 있는 경우** (운영자가 서버 주소를 알려준 경우): API 키 발급이 필요 없습니다.
  앱 **⚙️ 설정 → 데이터 연결 → 중계 서버 주소** 입력 → **저장하고 테스트** 후 **4단계**로 가세요.
  (중계 서버를 직접 만드는 방법: [중계서버-배포.md](중계서버-배포.md))
- **혼자 쓰는 경우**: 아래처럼 개인 API 키를 발급받아 **설정 → 개인 API 키 (선택)** 에 넣으세요.

### 개인 국토교통부 API 키 발급 (무료, 5~10분)

실거래 자료는 국토교통부가 공공데이터포털에서 무료로 제공합니다. 휴대폰 브라우저로 모두 할 수 있어요.

1. **회원가입/로그인**: https://www.data.go.kr 접속 → 우측 상단 메뉴 → 로그인 (카카오·네이버 간편 로그인 가능)
2. **매매 API 신청**
   - 검색창에 `아파트 매매 실거래가` 검색
   - **오픈 API** 탭에서 **「국토교통부_아파트 매매 실거래가 자료」** 선택
   - **활용신청** 누르기 → 활용목적: `참고자료` (또는 기타: "개인 시세 확인") 입력
   - 라이선스 동의 체크 → **활용신청** → 대부분 **자동 승인**됩니다
3. **전월세 API 신청** (전세·월세 보려면 꼭 필요!)
   - 같은 방법으로 `아파트 전월세 실거래가` 검색
   - **「국토교통부_아파트 전월세 실거래가 자료」** → **활용신청**
4. **인증키 복사**
   - 메뉴 → **마이페이지 → 데이터 활용 → Open API → 활용신청 현황** (또는 "개발계정")
   - 신청한 API 중 하나를 누르면 **일반 인증키(Encoding / Decoding)** 가 보입니다
   - 둘 중 아무거나 **길게 눌러 전체 복사** (두 API 모두 같은 키입니다)

> ⏰ 승인 직후에는 키가 실제로 동작하기까지 **1~2시간** 걸릴 수 있어요.

---

## 3단계. 앱에 개인 키 입력 (1분, 개인 키를 쓰는 경우)

1. 앱 아래 탭에서 **⚙️ 설정**
2. **개인 API 키 (선택)** 를 눌러 펼친 뒤 **일반 인증키** 칸에 붙여넣기
3. **키 저장하고 테스트** → `✅ 연결 성공! 매매 ○건 · 전월세 ○건` 이 나오면 끝!

| 실패 메시지 | 해결 방법 |
|---|---|
| `[매매] API 키 인증에 실패` | 키를 끝까지 복사했는지 확인. 승인 직후면 1~2시간 뒤 재시도 |
| `[전월세] API 키 인증에 실패` | **전월세 API 활용신청**을 안 한 경우. 2단계 3번 진행 |
| `인터넷 연결을 확인해 주세요` | 와이파이/데이터 확인 |
| `오늘 API 호출 한도를 초과` | 개발계정은 하루 1만 건. 내일 자동 복구 |

## 4단계. 알림 설정 (중요!)

1. **⚙️ 설정 → 알림 허용** → "알림을 보내도록 허용" → **허용**
2. **테스트 알림** 을 눌러 알림이 오는지 확인
3. **배터리 최적화 해제** (알림이 늦거나 안 올 때 꼭!)
   - **🔋 배터리 최적화 해제** 버튼 → 앱 정보 화면 → **배터리** → **제한 없음** 선택
   - 삼성: 설정 → 배터리 → 백그라운드 사용 한도 → **사용하지 않는 앱을 절전 상태로 전환 끄기** 또는 실거래 알리미를 **절전 예외 앱**에 추가
4. **확인 주기**: 기본 3시간. 국토부 자료는 보통 하루 한 번 갱신되므로 3~6시간이면 충분합니다.

---

## 5단계. 사용하기

1. **🔍 단지 찾기** → 시·도 → 시·군·구 선택
2. 단지 목록에서 원하는 아파트 선택 (검색 가능)
3. **매매 / 전세 / 월세** 탭에서 실거래 내역·최근 1개월 통계·추이 그래프 확인
4. **🔔 ○○ 실거래 알림 받기** 누르기
   - 즉시: **최근 한 달 실거래**가 알림으로 도착
   - 이후: **새로 신고된 거래**, **거래 해제**가 생길 때마다 알림
5. **🔔 내 알림** 탭에서 구독 단지 관리, 알림함 확인, **지금 새 실거래 확인**

> 💡 실거래는 계약 후 **30일 이내** 신고됩니다. 그래서 "최근 거래"는 시간이 지나면서 계속 추가되고, 앱은 이번 달·지난달 자료를 반복 확인해 새로 올라온 것만 알려줍니다.

## 6단계. 업데이트 받기 (선택)

새 버전은 GitHub 저장소의 **Releases**에 올라옵니다. 휴대폰에서 새 APK를 받아 **기존 앱 위에 설치**하면 설정·구독이 그대로 유지됩니다.

PC 없이 GitHub 서버가 APK를 자동으로 빌드하게 하려면, 한 번만 아래 설정을 해두세요 (휴대폰 브라우저에서 가능):

1. GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
2. 두 개 등록 (값은 함께 받은 `서명키-보관용.txt` 파일 참고)
   - `ANDROID_KEYSTORE_BASE64`
   - `ANDROID_KEYSTORE_PASSWORD`
3. 이후 코드가 바뀌면 **Actions** 가 자동으로 같은 서명의 APK를 만들어 **Releases** 에 올립니다.
   (수동 실행: Actions → Android APK → **Run workflow**)

> ⚠️ 서명키 파일은 **절대 공개하지 마세요.** 잃어버리면 업데이트 시 앱을 지우고 다시 설치해야 합니다(구독 초기화).

## 자주 묻는 질문

**Q. 앱을 꺼도 알림이 오나요?**
네. 앱을 닫아도(최근 앱 목록에서 지워도) 안드로이드가 주기적으로 확인합니다. 휴대폰을 재부팅해도 유지됩니다. 단, 배터리 최적화가 켜져 있으면 늦어질 수 있어요.

**Q. 데이터 요금이 많이 나오나요?**
확인 1회에 지역당 수십 KB 수준이라 거의 들지 않습니다.

**Q. 찾는 단지가 목록에 없어요.**
최근 6개월간 거래가 1건도 없는 단지는 목록에 나오지 않습니다.

**Q. 아이폰에서도 쓸 수 있나요?**
APK는 안드로이드 전용입니다. 아이폰은 웹 버전(서버 배포 필요)을 사용해야 합니다. README의 "웹 버전" 참고.
